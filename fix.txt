# Feature parity with Python argparse

Items are checked off as they are implemented and verified.

## Parser construction and argument containers

- [x] `parents=` parser inheritance, including parent argument groups and mutually exclusive groups
- [x] `add_argument_group(title:, description:)` and group help layout
- [x] `add_mutually_exclusive_group` inside an argument group
- [x] `conflict_handler: "error" | "resolve"`
- [x] `formatter_class:` and the built-in formatters (`HelpFormatter`, `RawDescriptionHelpFormatter`, `RawTextHelpFormatter`, `ArgumentDefaultsHelpFormatter`, `MetavarTypeHelpFormatter`)
- [x] custom `HelpFormatter` subclasses

## Arguments and actions

- [x] `add_subparsers` with `dest`, `required`, `help`, `metavar`, `title`, `description`, `prog`, aliases, custom parser classes, nested subparsers, and subcommand help
- [x] tuple `metavar` values, including validation against `nargs`
- [x] `argparse.SUPPRESS` for `dest` and `nargs`
- [x] `deprecated=` for options, positionals, and subcommands
- [x] custom `Action` classes / action registry
- [x] callable `type=` values (not only a Crystal block)
- [x] `FileType` and file objects in namespaces
- [x] `ArgumentTypeError` for user supplied converters
- [x] public action/nargs constants (`OPTIONAL`, `ZERO_OR_MORE`, `ONE_OR_MORE`, `PARSER`, `REMAINDER`, `SUPPRESS`) and `BooleanOptionalAction`
- [x] built-in `complex` type and Python numeric underscore validation (added during conformance work)

## Parsing

- [x] `namespace=` argument for `parse_args` and `parse_known_args`
- [x] `parse_intermixed_args` and `parse_known_intermixed_args`
- [x] `fromfile_prefix_chars=` and `convert_arg_line_to_args`
- [x] `suggest_on_error=` "did you mean" hints for choices and subcommands

## Messages and output

- [x] `suggest_on_error` wording matches CPython
- [x] message translation hook (gettext-style)
- [x] `parser.exit(status, message)` and `ArgumentParser.print_message` extension points
- [x] help rendering for suppressed groups, raw text, defaults, and metavar-type formatters

- [x] Regenerate the conformance fixtures
